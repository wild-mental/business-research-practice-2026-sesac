# 산업 및 비즈니스 분석 기초 프레임워크 학습

SeSAC 2026 과정 실습 저장소.

산업 구조에서 출발해 시장 규모로, 다시 개별 고객의 상황으로 좁혀 들어가는 순서로 분석 프레임워크를 다룬다. 앞 챕터의 산출물이 뒤 챕터의 입력이 되도록 구성한다.

## 학습 챕터

| # | 주제 | 층위 |
|---|------|------|
| 01 | Porter's Five Forces 모델 | 산업 |
| 02 | 기업 내부 활동의 가치 사슬 분석 | 산업 |
| 03 | 핵심 성공 요인(KSFs, Key Success Factors) 분석 | 산업 |
| 04 | TAM-SAM-SOM 과 Market Segment Map | 시장 |
| 05 | 페르소나, 페르소나 스펙트럼, 고객 여정지도 | 고객 |
| 06 | 시장기회 분석 : 기회점수(OS) 기반 우선순위 판단 | 시장 ↔ 고객 |
| 07 | 고객 상황을 객관화하는 JTBD(Jobs-To-Be-Done) 분석 | 고객 |
