# 산업 및 비즈니스 분석 기초 프레임워크 학습

SeSAC 2026 과정 실습 저장소.

산업 구조에서 출발해 시장 규모로, 다시 개별 고객의 상황으로 좁혀 들어가는 순서로 분석 프레임워크를 다룬다. 앞 챕터의 산출물이 뒤 챕터의 입력이 되도록 구성한다.

## 학습 챕터

| # | 주제 | 층위 |
|---|------|------|
| 01 | Porter's Five Forces 모델 | 산업 |
| 02 | 기업 내부 활동의 가치 사슬 분석 | 산업 |
| 03 | 핵심 성공 요인(KSFs, Key Success Factors) 분석 | 산업 |

| 05 | 페르소나, 페르소나 스펙트럼, 고객 여정지도 | 고객 |
| 06 | 시장기회 분석 : 기회점수(OS) 기반 우선순위 판단 | 시장 ↔ 고객 |
| 07 | 고객 상황을 객관화하는 JTBD(Jobs-To-Be-Done) 분석 | 고객 |

## 분석 대상

| 번호 | 대상 시장 | 다룬 챕터 |
|---|---|---|
| ① | 이미지 & 숏폼 영상 중심의 위치기반 SNS | 01 · 02 · 03 |
| ② | 미래형 수소(연료전지) 전기 승용차 | 01 · 02 · 03 |
| ③ | 아시아 식량 재분배(잉여-부족 매칭) 플랫폼 | 04 · 05 |

①②는 서로 대비되는 한 쌍으로 챕터 01~03을 관통한다. ③은 챕터 04에서 새로 도입된 별개 대상이며, 챕터 05가 04의 Segment Map을 입력으로 받아 이어진다.

### 챕터별 문서 규칙

- **`분석-방법론.md`** — 해당 프레임워크의 방법론과 **산출물 포맷 규격**. 규격 절이 있어야 다음에 같은 방법론을 써도 같은 수준의 결과물이 나온다.
- **`분석-NN-*.md`** — 대상별 분석. 0절에서 분석 단위를 먼저 못 박는다.
- **`비교-*.md`** — 대상이 둘 이상일 때 필수. 개별 분석 문서 안에 비교를 섞지 않는다.
- **`리서치-원본/`** — 외부 리서치를 근거로 삼았다면 원문을 함께 보존한다. 링크만 남기면 링크가 죽는 순간 근거가 사라진다.
